# ☕ ChaiTube - Video Sharing Platform

> A fully functional video streaming platform inspired by YouTube, built with the MERN Stack.


---

## 💡 About the Project
ChaiTube is a video hosting web application where users can upload, watch, like, and comment on videos. It features a complex backend to handle video files and a modern frontend for a seamless user experience.

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Redux Toolkit
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **File Storage:** Cloudinary (for Images & Videos)
- **Authentication:** JWT (JSON Web Tokens)

## ✨ Key Features
- **🎥 Video Upload:** Users can upload videos with thumbnails.
- **👍 Engagement:** Like, Dislike, and Subscribe to channels.
- **💬 Comments:** Real-time commenting system.
- **📂 Dashboard:** Manage uploaded videos and channel stats.
- **📱 Responsive:** Optimized for Mobile and Desktop.
